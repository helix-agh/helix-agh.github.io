We are happy to announce that our paper **"lonkit: A Python toolkit for Local
Optima Networks in continuous and discrete search spaces"** has been accepted
for publication in **SoftwareX**!

The paper describes **lonkit**, our open-source library for building, analyzing
and visualizing Local Optima Networks. With a few lines of code you can sample
a LON of any Python function (Basin-Hopping) or discrete problem (Iterated
Local Search), compress it into a CMLON, compute funnel metrics, and plot it in
2D or 3D — for example, to watch Number Partitioning become hard across its
phase transition.

This is joint work with Gabriela Ochoa (University of Stirling) and Jacek
Mańdziuk (Warsaw University of Technology). Try it with `pip install lonkit` —
see the [documentation](https://helix-agh.github.io/lonkit) and the
[GitHub repository](https://github.com/helix-agh/lonkit).
